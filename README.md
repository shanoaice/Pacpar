# Pacpar

> :construction: This is a work in progress.

Pacpar is a modern .NET binding and command-line interface for Arch Linux's libalpm, designed for high performance, type safety, and ergonomic package management.

[Pacpar.Alpm](./src/Pacpar.Alpm/README.md) is a C# FFI wrapper library for libalpm, also hosted in this repository.
