# Pacpar

> :construction: This is a work in progress.

Pacpar is a modern .NET binding and command-line interface for Arch Linux's libalpm, designed for high performance, type safety, and ergonomic package management.

## Subprojects

- [Pacpar.Alpm](./src/Pacpar.Alpm/README.md) is the C# FFI wrapper library for libalpm
- Pacpar.Alpm.FSharp (WIP) is a declarative F# library (based on Pacpar.Alpm) for libalpm
- Pacpar.CLI (WIP) is the feature-rich command-line interface and AUR helper built with Pacpar.Alpm
